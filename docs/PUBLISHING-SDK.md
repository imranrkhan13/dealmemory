An earlier saved token was rejected; he may need a new token. Never paste it into chat or this repository. For Python: `python -m build packages/python` then inspect distributions and `python -m twine upload dist/*`. Do not run these publishing commands from an agent session. After ownership and installation have been verified, update lib/sdk-install.ts and its published flag and add the verified registry installation flows.

Browser SDK retries network/429/server failures with bounded exponential jitter, retains at most 1000 queued events per project, and drops terminal invalid batches. On 409 the server already stored valid non-conflicting events; the SDK drops conflicting events and acknowledges those accepted events, so none need resending. Python is synchronous, times out, raises on errors and never retries indefinitely. Callers can retain their own stable event ids for HTTP retries. URL queries/fragments are stripped by default and always stripped on the server. URL paths can contain personal data: a configurable path-pattern allowlist is a recommended follow-up.
